## How to Run Locally

### Prerequisites
- Node.js (v16.14.0 or higher)
- npm (v8.0 or higher)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your web browser.

### 3. Build for Production
```bash
npm run build
```
This generates the optimized, minified production assets in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## Production Deployment Guide

### Option 1: Vercel (Recommended)
1. Push your repository to GitHub, GitLab, or Bitbucket.
2. Import the project into Vercel (`https://vercel.com`).
3. Vercel automatically detects Vite:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Click **Deploy**.

### Option 2: Netlify
1. Create a `netlify.toml` file or connect your repository via Netlify UI.
2. Build Settings:
   - Build command: `npm run build`
   - Publish directory: `dist`
3. Click **Deploy Site**.

### Option 3: Traditional Nginx Server
Copy the contents of `dist/` to your Nginx root (e.g. `/var/www/britec`) and configure:
```nginx
server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/britec;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```
